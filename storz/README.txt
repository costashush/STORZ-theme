STORZ V2.2 Lite
================

Included:
- centered layout
- minimal header with logo and optional text
- optional search module
- optional footer
- admin form builder
- multi-step forms using field step numbers
- prebuilt forms
- starter pages: Home, Contact, Login, Quote Request
- login/logout shortcodes
- edit/delete forms

Shortcodes:
- [storz_form id="1"]
- [storz_form slug="contact-form"]
- [storz_login_form]
- [storz_logout_link]
- [storz_account_panel]

How multi-step works:
- in the form builder, each field has a Step number
- fields with the same step are shown together
- the frontend automatically shows Previous / Next buttons

Logo:
- upload logo from Appearance > Customize > Site Identity
- optional text is controlled in Appearance > STORZ Theme Options
